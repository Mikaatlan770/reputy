REPUTY - Roadmap & Tâches

Document généré le 11 janvier 2026 • Liste complète des développements à réaliser

🔴 PRIORITÉ HAUTE (Production-ready)

1. Backend & Infrastructure

  • Créer une vraie base de données (PostgreSQL/MongoDB)
  • Remplacer les données mock par des vraies requêtes BDD
  • Implémenter l'authentification réelle (NextAuth.js ou Clerk)
  • Configurer les variables d'environnement production
  • Déployer le backend (Vercel/Railway/AWS)
  • Configurer un domaine (reputyapp.com)
  • Mettre en place HTTPS/SSL

2. Intégration Google Business Profile

  • Implémenter l'OAuth2 Google
  • Connecter l'API Google Business Profile
  • Récupérer les avis en temps réel
  • Publier les réponses aux avis
  • Synchroniser les infos établissement
  • Gérer le refresh token automatique
  • Webhook pour nouveaux avis (polling ou Pub/Sub)

3. Intégration Stripe (Production)

  • Créer les produits/prix dans Stripe Dashboard
  • Remplacer les stripePriceId mock par les vrais IDs
  • Implémenter createCheckoutSession avec vraie API Stripe
  • Implémenter le portail client Stripe
  • Tester le flux complet : paiement → webhook → activation
  • Gérer les échecs de paiement et relances automatiques

4. Envoi SMS réel

  • Créer compte Twilio/Vonage/OVH SMS
  • Implémenter l'API d'envoi SMS
  • Gérer les erreurs et logs d'envoi
  • Créer le service de liens courts (rpt.ly)
  • Tracker les clics sur liens

5. Envoi Email réel

  • Configurer Resend/SendGrid/Mailgun
  • Créer les templates emails (HTML responsive)
  • Implémenter l'envoi transactionnel
  • Tracker ouvertures et clics

7. Assistant IA (Production)

  • Intégrer OpenAI API (GPT-4 ou Claude)
  • Créer les prompts optimisés par ton et contexte
  • Gérer le Mode Santé dans les prompts (garde-fous médicaux)
  • Tracker l'usage réel des tokens
  • Implémenter le cache pour suggestions similaires
  • Ajouter champ consignes personnalisées par établissement

8. Extension Chrome Doctolib

  • Tester sur vraies pages Doctolib Pro (différents cabinets)
  • Améliorer la détection automatique des patients
  • Pré-remplissage automatique (nom, email, téléphone)
  • Publier sur Chrome Web Store
  • Gérer les mises à jour automatiques
  • Support Firefox (WebExtension)

9. Génération QR/NFC

  • Générer de vrais QR codes (lib qrcode.js)
  • Créer les pages de collecte personnalisées (branding)
  • Implémenter le tracking scans NFC
  • Créer le système de liens courts avec analytics
  • Export QR en PNG/SVG haute résolution

🟢 PRIORITÉ BASSE (Améliorations)

10. UX & Design

  • Mode sombre (dark mode)
  • Animations et transitions fluides
  • Notifications en temps réel (WebSocket/SSE)
  • PWA pour mobile
  • Onboarding nouvel utilisateur (wizard)
  • Tour guidé des fonctionnalités

11. Analytics avancés

  • Analyse de sentiment IA sur les avis
  • Extraction automatique de tags/thèmes
  • Benchmarks sectoriels
  • Export PDF des rapports
  • Alertes personnalisées (avis <3*, mots-clés)

12. Concurrence (Production)

  • Intégrer Google Places API pour vrais concurrents
  • Scraping éthique des avis concurrents
  • Alertes nouveaux concurrents dans la zone
  • Comparatifs automatisés et rapports

13. Multi-langue

  • i18n (français, anglais, hébreu)
  • Détection langue automatique
  • Traduction des templates SMS/Email
  • Interface RTL pour l'hébreu

14. Sécurité & Compliance

  • RGPD : export/suppression données utilisateur
  • Logs d'audit complets
  • Rate limiting API
  • Protection CSRF/XSS
  • Backup automatique BDD (quotidien)
  • Tests de pénétration
